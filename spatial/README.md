# Spatial Design 004 — Global Gaming Center
Additive walkable prototype at spatial/index.html. Production root, existing game index, NNB, NLC, World, HQ1 and HQ2 are not changed.

Departments: Chess (anchor department with a static 3D starting position and official source links), Global Sports (concept), 1AGE Originals (Besuto Run concept), Blockchain Games (existing discovery), Virtual Worlds (external launch links for Decentraland and Upland). NNB is a lifestyle/training space, not an original game.
 
## Proposed future work, subject to founder review
- Chess: legal move validation, clocks, local and online play, accessibility, server-authoritative matches, anti-cheat and a distinct 1AGE rating. Source/date/time control for external FIDE and online platform ratings; check redistribution permissions before ingestion. Never represent native ratings as official FIDE ratings.
- Sports: opt-in adult athlete identity, permissions for likeness/data, original 1v1 basketball mechanics and separate game ratings. Youth participation needs separate privacy, safeguarding and consent design; do not ingest identifiable youth rankings or publish youth likenesses in this prototype. No wagers, gambling, transferable rewards for minors or speculative athlete tokens.
- Blockchain discovery: index independent games and worlds, label external account requirements and supported networks. No implied partnership, SSO or shared asset support.
- Cash: off-chain internal credits, optional non-wagered first-party game uses after compliance review. Wallet-free play; no live payments or redemption integration.
- Original titles: independently authored code, graphics and brands; no copying protected NBA 2K/Madden assets or software.

Foundation files ported from Page commit c1414ed39f45d4c0ea7b87895c708f2f61e84b49 with 1.75m camera height matching Space. Reuses Games local renderer, existing gamepad and Earth asset. HQ1 is visual benchmark, not a verified match.

Before release: test rendering, screenshots, chessboard orientation and legibility, collision, links, portrait/landscape iPhone and external gamepad; measure FPS and check graphics settings. Review concurrent changes and obtain approval before merging or changing root entry. No live matches, synced ratings, athlete records, playable chess or Besuto Run in this build.
